# Spec Delta

## REMOVED Requirements

### Requirement: Детектор дрейфа версии комплекта
**Reason**: Детектор (введён 2.1.0, паттерн Terraform-lock из
`research/upgrade-config-sync/`) не окупился: за бампы 2.1.0→2.5.0 ни одна
секция `docs/upgrade.md` не потребовала обязательного действия в проекте —
срабатывание детектора не давало адресату действий. Читатель `plan.md` —
LLM, толерантное чтение уже штатный механизм комплекта для легаси;
версионные маркеры обслуживают строгих парсеров. В экосистеме популярных
скиллов рантайм-детектора дрейфа нет ни у кого (ближайший паттерн —
superpowers «Skills evolve. Read current version» — решает противоположно).
Продюсер и потребитель комплекта одно лицо. Решение человека 2026-11-21
(эксплор, вариант B).
**Migration**: План прогона перестаёт хранить строку
`ship-kit: <версия>`; Шаг-0 `task` не читает манифест и не сверяет версию.
Существующие планы со строкой `ship-kit: <версия>` читаются толерантно:
строка игнорируется и не переписывается, сообщений о версии нет. Поле
`version` манифеста `qwen-extension.json` и `docs/upgrade.md` остаются
changelog'ом — рецепты читаются человеком при переустановке комплекта;
дисциплина «change, меняющий проектные ожидания или поведение Шага-0,
бампает версию и пишет секцию» сохраняется.
