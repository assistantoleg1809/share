# Proposal

## Why

Сессия 5d4979c9: пуш упал (нет remote), но PR всё равно создан — «PR в
никуда». Требование пользователя: при таймаутах git/MCP/иного повторы
обязаны быть, и без повторного разрешения.

## What Changes

- **ADDED** «Транспортные сбои — автоматический повтор»: таймаут/обрыв
  MCP или git → авто-повтор до 2 раз, без вопросов и без повторного
  гейта; исчерпаны — честная ошибка.
- **ADDED** «PR — только после успешного пуша»: пуш не выполнен/невозможен
  → стоп, PR не создаётся.

- `skills/{task,pr,ci}/SKILL.md` (строка транспортных повторов; pr —

  пуш реален; копия переустанавливается.
