# Proposal

## Why

Задачи бывают двух типов — бизнес-задачи и технические задачи — и
выполняются разными наборами скиллов проекта. Сегодня `task` тип не
различает: работает один и тот же ход для любой задачи, тип знает
только сам агент, неявно. Нужен явный детерминированный механизм:
определить тип на Шаге-0 и собрать соответствующий набор — тем же
способом (слоты, дословные метки, каскад), каким после skill-slots
разрешается исполнитель спеки.

## What Changes

- Словарь слотов пополняется двумя слотами типов: `business` и
  `technical`; метка `slot:<тип>` на скилле означает членство в наборе
  этого типа (обе метки — универсальный скилл, в обоих наборах; ни
  одной — вне конвейера типов).
- `task` на Шаге-0 определяет тип задачи каскадом: дословный маркер
  `(business)`/`(technical)` в задании → поле/лейбл тикета трекера →
  правило конвенции проекта → не определился → **business** (дефолт) со
  строкой в отчёте.
- Задача выполняется набором своего типа: скиллы сессии с меткой слота
  типа либо список из конвенции (запись конвенции сильнее меток).
- Пустой набор — асимметрично: тип `technical` → правка **без
  применения скиллов**, не спрашивая; тип `business` → один вопрос
  человеку (продолжить без скиллов / назвать скиллы) — бизнес-задачи
  обычно идут через скиллы.
- Смешанная задача расщепляется в плане прогона на части с типами
  (каждая часть — по правилам своего типа); тикет не делится.
- Диагностика: тип, источник (задание/трекер/конвенция/дефолт) и состав
  набора или «без скиллов» — одной строкой в плане/отчёте Шага-0.
- Манифест комплекта 2.2.0 → 2.3.0, рецепты — секцией в docs/upgrade.md.

## Capabilities

### New Capabilities

(нет — меняется поведение существующей возможности)

### Modified Capabilities

- `base-skills`: ADDED «Типы задач и наборы» — детекция типа каскадом,
  наборы слотами, асимметричный пустой набор, расщепление смешанных
  задач, диагностика; MODIFIED «Слоты переменных скиллов» — словарь
  пополняется слотами `business`/`technical`, метка слота означает
  также членство в наборе типа, не только исполнение роли.
