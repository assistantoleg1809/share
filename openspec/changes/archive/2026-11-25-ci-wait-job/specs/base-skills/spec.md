# Spec Delta

## ADDED Requirements

### Requirement: Ожидание джобы CI

`ci` после подтверждённого запуска джобы MUST активно ждать исхода:
опрашивать статус через MCP CI до SUCCESS/FAILURE/UNSTABLE, без
вопроса человеку — ожидание входит в слот, карточкой не оформляется
(карточка запуска уже авторизовала и запуск, и ожидание). Интервал:
задание `poll=<сек>` > конвенция проекта > дефолт 600 секунд; первый
опрос — сразу после запуска; каждый опрос — свежий вызов. Долгая
джоба — промежуточные отчёты этапами.

#### Scenario: ожидание без вопроса

- **WHEN** карточка запуска подтверждена «да», джоба запущена и ещё идёт
- **THEN** ci опрашивает статус до исхода; вопрос «ждать ли?» не задаётся; первый опрос — сразу после запуска, далее с интервалом по лесенке (дефолт 600 секунд)

#### Scenario: долгая джоба

- **WHEN** джоба идёт дольше интервала опроса
- **THEN** ci продолжает опросы тем же интервалом и отчитывается этапами — не молчит и не спрашивает разрешения ждать

#### Scenario: исход завершает ожидание

- **WHEN** свежий опрос вернул SUCCESS/FAILURE/UNSTABLE
- **THEN** ожидание заканчивается: зелёная — слот закрыт, следующий слот по плану; RED — диагностика по kind-файлу
