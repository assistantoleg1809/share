# Proposal

## Why

Гейт необратимого в комплекте — «карточка-превью → явное "да" → действие», и
«да» модель трактует из свободного текста. На дешёвой модели расплывчатая
фраза человека («ну давай», «вроде ок», ответ на другое) может быть ошибочно
принята за подтверждение пуша/PR/запуска джобы. Исследование готовых
механизмов (`research/confirmation-gates/`, 2026-11-18): крупные инструменты
(Claude Code, Gemini CLI, Codex, ACP) согласие через структурированный выбор
не парсят текстом — решение пользователя 2026-11-18: переиспользовать паттерн
«структурный вопрос хоста».

## What Changes

- Вопрос-гейты (карточка «пуш+PR», карточка фикс-пуша, карточка запуска
  джобы; подтверждение чек-листа плана; переспрос flaky-повтора) при наличии
  в сессии **инструмента вопроса с закрытыми опциями** MUST задаваться этим
  инструментом: выбор утвердительной опции = «да», выбор опции отказа =
  стоп; свободный текст вне опций подтверждением NOT считается — ответ на
  содержание и один переспрос тем же инструментом, затем стоп.
- Имя инструмента комплектом не вшивается (как с инструментом
  спекирования): наличие определяется в рантайме по списку инструментов
  сессии.
- Инструмента нет (headless-прогон, чисто текстовый канал) — действующие
  правила свободного текста без изменений.
- Контракт отчёта не расширяется: источник подтверждения отмечается в теле
  отчёта как факт, строки GATE сохраняются.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `base-skills`: MODIFIED-требование «Гейты необратимого — три правила» —
  вопрос-гейт задаётся структурным инструментом при его наличии, согласие =
  утвердительная опция, текст вне опций ≠ подтверждение (+3 сценария).

## Impact

- `extensions/ship-kit/skills/task/SKILL.md` — подтверждение чек-листа плана
  (Шаг 0.2).
- `extensions/ship-kit/skills/pr/SKILL.md` — секция «Гейт — три правила»,
  карточки implement+pr и fix.
- `extensions/ship-kit/skills/ci/SKILL.md` — «Гейт запуска», flaky-повтор.
- `extensions/ship-kit/QWEN.md`, `extensions/ship-kit/docs/ship-kit.md` —
  инвариант гейтов и описание.
- `openspec/specs/base-skills/spec.md` — синк дельты при архивации.
- Установленная копия `~/.qwen/extensions/ship-kit` — переустановка.
- Очередь apply: сначала `pr-wait-merged` (уже ждёт), этот change — следом;
  оба правят `pr`/SKILL.md, конфликт текстов разрешается при применении.
