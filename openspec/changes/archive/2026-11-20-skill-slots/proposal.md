# Proposal

## Why

Исполнитель спекирования `task` сегодня ищет семантическим угадыванием
по description скиллов сессии: текст — не контракт, формулировка
поменялась — вызов сломался; поведение недетерминировано и по-разному
объясняется в двух местах (спека — угадывание, внешние скиллы —
перечень заданием). Исследование `research/cross-skillset-invocation/`
(2026-11-20, 13 систем): рантайм-угадывание по описанию как единственный
механизм не использует никто — зрелые системы ставят явный контракт
(декларация исполнителя / имя-слот) и детерминированный порядок
разрешения. Выбор человека 2026-11-20: идеи 1+2+4 — словарь слотов,
метка исполнителя, единый каскад.

## What Changes

- **Словарь нейтральных слотов** — имена ролей для переменных скиллов
  по образцу MCP-ролей комплекта; канонический слот: `spec`
  (спецификация изменения). Слот — часть контракта комплекта, имя
  инструмента в файлах комплекта по-прежнему не упоминается.
- **Метка исполнителя**: переменный скилл заявляет слот литеральной
  строкой `slot:<имя>` в description своего SKILL.md (несколько —
  через запятую); комплект читает метку дословным поиском по списку
  скиллов сессии. Семантическое угадывание по смыслу описания
  удаляется (**BREAKING** для проектов без метки: спек-скилл без
  `slot:spec` больше не находится — сработает правило слота
  «мини-дизайн»; миграция — рецепт `docs/upgrade.md`, манифест
  2.1.0 → 2.2.0).
- **Единый каскад разрешения слота**: задание > конвенция проекта >
  метки скиллов сессии > правило слота (`spec` без исполнителя →
  мини-дизайн в чате); несколько кандидатов — один вопрос. Конвенция
  (файл проектов) может перечислять набор скиллов без выбора одного —
  тогда один вопрос человеку с выбором из перечисленных. Одна лесенка
  вместо двух путей, той же формы, что лесенка аргументов.
- Неизвестные комплекту слоты в метках игнорируются (старое/новое не
  ломают друг друга).

Не входит (не выбрано человеком): манифест-файл фаз — макрос
`ship-kit.workflows.md` остаётся опцией без изменений (идея 3);
расширенная диагностика ненайденных слотов (идея 5); обёртки-шлюзы.
