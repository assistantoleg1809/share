# Design

## Context

Уровень 1 (структурный вопрос) закрыт change `gate-structured-question`
(2026-11-18) по выбору человека из исследования
`research/confirmation-gates`; уровни 2 и 3 отложены. См. proposal.md —
Why: текстовый фолбэк недоопределён.

## Goals / Non-Goals

**Goals:** закрыть текстовую ветку гейта закрытым списком дословных фраз
(default-deny) — уровень 2 исследования; переиспользовать существующее
правило «переспрос один раз, затем стоп».

**Non-Goals:** echo-nonce «да \<id\>» (уровень 3) — привязка ответа к
карточке в структурном канале уже даётся хостом; в текстовый канал
приходит по зафиксированному инциденту. Не меняем механику карточек,
pre-approved, повторов.

## Decisions

1. **Состав списка: «да», «ок», «подтверждаю», «подтверждаю \<действие\>».**
   «ок» включён сознательно: устойчивая привычка человека подтверждать
   коротким «ок» — без него список конфликтовал бы с практикой и провоцировал
   переспросы. Отказ: «нет», «стоп». Альтернатива «только да/подтверждаю»
   отвергнута как трение без прироста защиты: фразы равно однозначны.
2. **Default-deny, но не молчаливый отказ.** Нераспознанная фраза — не
   отказ, а «не решение»: ответ на содержание + один переспрос + стоп.
   Переиспользует правило текста-вне-опций уровня 1 — один механизм
   переспроса на оба канала. Anti-substring: совпадение — ответ **целиком**
   («ну да, наверное» ≠ «да») — явная защита под дешёвую модель
   (glm-5.3-flash), склонную к частичному матчингу.
3. **Формулировка «подтверждаю \<действие карточки\>»** — расширение
   существующего pre-approved-паттерна на интерактив: самая сильная фраза
   списка (называет действие), но не обязательная.
4. **Точки правки — по одному блоку на скилл**: task (блок «Структурный
   вопрос» в п.2 Шага-0), pr («Гейт — три правила»), ci («Гейт запуска») —
   заменить хвост «Инструмента нет — правила свободного текста…» на
   текстовый канал со списком; QWEN — инвариант гейтов; docs — п.2.
5. **Версия 2.3.0 → 2.4.0 + секция upgrade.md**: меняется поведение
   Шага-0/гейтов в текстовых каналах — детектор дрейфа сообщит прогонам.

## Risks / Trade-offs

- [«ок» в другой тональности («ок, но сначала…») формально входит в список]
  → фраза читается дословно целиком: «ок, но…» ≠ «ок» (не дословное
  совпадение) → переспрос; фиксируется строкой «дословно» в правиле.
- [Список слишком широк/узел для команды] → состав списка — одно место в
  трёх точках; расширение — маленьким change.

## Migration Plan

Бамп версии + рецепты upgrade.md («headless-прогоны: подтверждения теперь
только дословными фразами списка; расплывчатые ответы не трактуются как
да»). Откат — возврат текстов, проектного состояния нет.
