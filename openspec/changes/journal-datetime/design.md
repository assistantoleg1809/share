# Design

## Context

Журнал — часть plan.md с появления требования «Состояние прогона», но
формат записей не задан: записи пишутся произвольно («pr: PR создан»,
«ci: запуск #12»), момент события теряется. Задание (пользователь,
2026-11-20): все записи в журнал должны начинаться с даты и времени.

## Goals / Non-Goals

**Goals:**

- Хронология прогона читается из самого журнала: когда создан план,
  подтверждены гейты, создан PR, запускались джобы, писались ответы в
  PR.
- Единый формат во всех трёх скиллах-фазах.

**Non-Goals:**

- `issues.md` — записи-задачи о провалах имеют свою структуру;
  датируются отдельным change при необходимости.
- Переписывание/миграция легаси-журналов без дат.
- Секунды и часовой пояс в формате.

## Decisions

1. **Префикс `ГГГГ-ММ-ДД ЧЧ:ММ`, локальное время.** ISO-подобный формат
   сортируется лексикографически; минуты достаточны (события фаз реже
   минуты не различаются); локальное время — без пересчёта поясов.
   Альтернатива ISO-8601 с секундами и зоной отвергнута — шум в
   строке, которую читает человек при возобновлении.
2. **Правило — в точках записи каждого скилла, не только в QWEN.**
   Прецедент «императив в двух местах» (pr-own-comments): исполнитель
   фазы может не читать QWEN. Правило продублировано в `task` (создание
   плана), `pr` (id своих комментариев), `ci` (отметки плана).
3. **Легаси-планы не переписываются.** Возобновление читает журнал как
   есть; новые записи — только с датой и временем.

## Risks / Trade-offs

- [Запись со «выдуманной» датой без сверки с часами] → формат
  фиксированный и greppable (`^\d{4}-\d{2}-\d{2} \d{2}:\d{2}`), проще
  контролировать, чем относительные метки.
- [Смешение форматов в одном легаси-журнале] → допускается: старые
  записи остаются, новые идут с префиксом.

## Migration Plan

Текстовые правки трёх скиллов, QWEN.md, docs; синк дельты при
архивации; копия переустанавливается.
