# Proposal

## Why

Журнал прогона в `runs/<ПРОЕКТ>/<КЛЮЧ>/plan.md` накапливает события
фаз (создание плана, гейты, PR, запуски джоб, id своих комментариев),
но записи не несут момента события: при возобновлении и разборе
провала нельзя сказать, когда что происходило и сколько длились паузы;
хронология восстанавливается только по git/статусам, которых у журнала
нет.

## What Changes

- **Формат записей журнала**: каждая запись журнала плана прогона
  начинается с даты и времени — `ГГГГ-ММ-ДД ЧЧ:ММ` (локальное время
  машины), затем событие. Пример: `- 2026-11-20 14:35 · pr: PR #128
  создан, ожидание MERGED`.
- Записи без даты и времени не пишутся; легаси-журналы без дат
  читаются как есть, не переписываются.
- Затронутые точки записи: `task` (создание плана и записи фаз),
  `pr` (id своих комментариев, события PR), `ci` (отметки плана).
