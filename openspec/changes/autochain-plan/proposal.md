# Proposal

## Why

Живые прогоны (сессии пользователя 2026-11-15) показали два разрыва
ожиданий: (1) план прогона не создавался, когда задание не перечисляло
внешних скиллов («чек-лист не нужен»), а пользователь ждёт план всегда;
(2) фаза `task` завершилась HANDOFF-строкой и остановилась — пользователь
ждал безостановочного продолжения. Требование пользователя: план —
всегда; фазы вызываются без остановки по плану; одиночный вызов скилла
человеком — выполняется только он.

## What Changes

- **MODIFIED** «Порядок прогона с внешними скиллами»: план
  `skill-runs/<КЛЮЧ>/plan.md` создаётся **всегда** при первом вызове
  фазы по ключу. Задание перечислило внешние скиллы → чек-лист с одним
  подтверждением (как сейчас); не перечислило → план = фазы комплекта
  по умолчанию `task → pr 🔒 → ci 🔒`, без вопроса.
- **MODIFIED** «Три скилла-фазы»: закрытый слот продолжается следующим
  незакрытым слотом плана **без остановки** (цепочка авторизована
  планом; паузы — только 🔒-гейты и вопросы правил; конец плана — стоп).
  Одиночный вызов скилла человеком вне плана выполняется без цепочки.
- **MODIFIED** «Состояние прогона»: план всегда, включая прогоны без
  внешних скиллов; слот ci открывается после MERGED PR.
- Тексты `task`/`pr`/`ci`: Шаг 0.2 (план всегда) и секции завершения
  фазы; QWEN.md/docs — по строке.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `base-skills`: три требования выше (авто-цепочка по плану вместо
  запрета авто-переходов; план безусловный).

## Impact

- `extensions/ship-kit/skills/{task,pr,ci}/SKILL.md`, `QWEN.md`,
  `docs/ship-kit.md`; установленная копия переустанавливается.
- Гейты не меняются: безостановочность НЕ касается карточек 🔒 и
  вопросов правил. Это не возврат движка v2: «цепочку» ведёт не
  диспетчер, а подтверждённый (или дефолтный) чек-лист плана.
