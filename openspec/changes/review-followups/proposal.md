# Proposal

## Why

Архитектурно-кодовое ревью `extensions/ship-kit` от 2026-11-20
(`.qwen/reviews/2026-11-20-extensions-ship-kit.md`) нашло 4 Suggestion:
внутреннее противоречие мейн-спеки (легаси-пути), неопределённый
приоритет тип-набора против перечня задания (flash-риск: случайный
выбор), разорванное предписание в task/SKILL.md (flash-риск: потеря
правила), имя спек-инструмента в поставке docs. Человек подтвердил
исправление всех четырёх («делать все», 2026-11-20).

## What Changes

- **f1**: мейн-спека — два места требуют легаси-пути `skill-runs/`
  для НОВЫХ артефактов (план — требование «Порядок прогона с внешними
  скиллами», issues.md — сценарий «PR отклонён» требования «Ожидание
  мержа PR»); синк на `runs/<ПРОЕКТ>/<КЛЮЧ>/`. Применяется синком
  дельты при архивации; файлы комплекта уже консистентны.
- **f2**: приоритет перечня задания над тип-набором — строка в task
  Шаг-0 п.4 + дубли в QWEN и docs п.4 + сценарий в дельте «Типы задач
  и наборы».
- **f3**: task/SKILL.md — склеить разорванное предписание об
  отсутствующем alias, список «Роли алиасов» после фразы (как в ci).
- **f4**: docs/ship-kit.md чек-лист адаптации — «(git/openspec/node)»
  без имени инструмента.
- Манифест 2.4.0 → 2.5.0 + секция docs/upgrade.md (f2 — поведенческая
  строка Шага-0).
