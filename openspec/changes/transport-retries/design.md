# Design

## Context

Транскрипт 5d4979c9: `git push` → «origin does not appear to be a git
repository», далее «Хост-слой — MCP bitbucket… Создаю PR» — дефект: PR
без пуша. Повторов транспорта в текстах не было (только flaky-джобы).

## Goals / Non-Goals

**Goals:** транспортные сбои ретраятся молча (гейт уже авторизовал
действие — повтор не новое действие); PR физически невозможен без
пуша; песочницы с origin — пуш реален, правило проверяемо живьём.
**Non-Goals:** retry-политики бэкенда, повторы упавшей джобы CI
(остаются переспросом одной строкой).

## Decisions

1. Авто-повтор — до 2, только для сбоев, не изменивших состояние
   (таймаут/обрыв/сеть). Ошибка ответа сервера (4xx/логическая) — не
   транспорт: к ней ретрай не применяется.
2. «PR только после пуша» — на уровне скилла pr: неудачный пуш после
   транспортных повторов = стоп; карточка «пуш+PR» остаётся единой,
   apply просто не доходит до PR.
3. Песочницы: `.origin/` (bare) + `git remote add origin` + push main
   в сборщиках; `.gitignore` с `.origin/`.

## Risks / Trade-offs

- [Мок PR не проверяет remote] — правило в скилле + реальный origin в
  песочнице делают случай воспроизводимым и чинимым.

## Migration Plan

Тексты + сборщики + переустановка; откат — git revert.
