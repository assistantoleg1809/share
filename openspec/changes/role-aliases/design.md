# Design

## Context

Роли-алиасы выбраны пользователем (2026-11-15): tracker/docs/repo/
build/deploy/quality + vuln + chat; одна роль может иметь несколько
MCP. Заменяет русский список ролей из aliases-perms-pr-status.

## Goals / Non-Goals

**Goals:** один канонический словарь ролей в спеке, скиллах и
конвенциях; синтаксис нескольких MCP на роль; vuln в диагностике CI.
**Non-Goals:** конкретные имена серверов в поставке; изменение моков
(серверы песочниц остаются jira/wiki/bb/jenkins — роли лишь мапят их).

## Decisions

1. docs вместо wiki — выбор пользователя; в текстах рядом с EN-именем
   даётся русское пояснение («docs (вики/runbook)»).
2. Несколько MCP на роль: значение через запятую; чтение по всем,
   запись — куда названо заданием, иначе вопрос. Не «первый
   доступный» — выбор получателя записи не решение скилла.
3. vuln в протоколах kind-файлов: известные уязвимости зависимостей по
   тексту ошибки (build) и по компоненту стенда (deploy) — если MCP
   роли передан.
4. Песочницы: конвенция говорит ролями; имена серверов в settings и
   permissions.allow не меняются (моки те же).

## Risks / Trade-offs

  пояснениями рядом с серверами.
