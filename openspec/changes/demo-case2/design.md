# Design

## Context

Кейс-1 GREEN (21c9166). Урок: openspec-скиллы проектные — в /tmp их не
было, discovery взял brainstorming; правила спеки человек называть в
промпте не должен. Новый режим: пользователь запускает прогон сам
(интерактивно, карточки гейтов подтверждает лично), мы поставляем
«где и что».

## Goals / Non-Goals

**Goals:** воспроизводимый кейс-2 (замечание на PR → CI-тесты ❌ →
Jenkins-конфиг ❌ → фиксы, включая посторонний тех-PR); правила спеки
проекта применяются из файла проектов автоматически; промпты
минимальные.

**Non-Goals:** прогон агентом (только стенд и маршрут); правки
базы/спек; RUN-2 до фактического прогона.

## Decisions

1. **Правила спеки — раздел файла проектов** («Конвенции спеки —
   правила проекта»): инструмент — openspec-скилл (при нескольких
   кандидатах в списке скиллов выбирается он — подсказка проекта
   сильнее discovery, но не конфигурация комплекта); имя изменения
   `<ключ стори>-<slug задачи>` (родитель из jira). Промпт вызова 1 —
   только задача. Скиллы копируются сборщиком в песочницу — правила
   применимы без слов человека.
2. **События детерминированы сидом**: ловушка округления (jira: «до
   целых», CI-тест платформы: до 2 знаков) → build #1 FAIL_TEST
   (RELATED: task-diff); опечатка `STAND_HOS` в Jenkinsfile репо →
   deploy IFT FAIL_JENKINSCFG (config, посторонний, вне диффа задачи →
   тех-ветка от main, спека не тронута); замечание ревьюера инъекцией
   в PR-1 (autoMerge=false → PR OPEN; MERGED ставится служебной
   командой после резолва) — «пустой массив в total».
3. **Маршрут для человека**: одна интерактивная сессия
   `qwen --model glm-5.3-flash` в песочнице; 13 сообщений по списку;
   между ними — однострочные node-команды во втором терминале
   (замечание, MERGED×3). Карточки гейтов подтверждает сам («да») —
   pre-approved фразы в промптах не нужны.

## Risks / Trade-offs

- [flash выберет не openspec при нескольких кандидатах] → правило
  файла проектов + openspec-скиллы в песочнице; отклонение честно
  попадёт в анализ сессии.
- [/tmp-песочница умрёт до запуска] → в SCENARIO-2 команда пересборки.
- [Замечание/исходы зависят от порядка state] → служебные команды
  меняют ровно одно поле; сид сбрасывается пересборкой.

## Migration Plan

Только добавление файлов; откат — удаление.
