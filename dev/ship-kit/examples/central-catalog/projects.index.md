# Файл проектов — calc (demo)

Единственное место правды проекта для сборки вызовов ship-kit: агент
сессии читает этот файл как обычный контекст и подставляет значения в
аргументы вызова. Скиллы базы (`task`/`pr`/`ci`) файл не читают и
формата не знают.

## calc

- Ключ задач: PRJ (Jira)
- Репозиторий: git@git.corp:team/calc.git
- Базовая ветка: main (пуш в неё запрещён)
- Рабочие ветки: задачи — `feature/<КЛЮЧ>`, баги — `bugfix/<КЛЮЧ>`
- Описание: калькулятор отчётов; сборка ~6 мин, деплой по стендам

## MCP-серверы (alias = значение аргумента вызова)

- mcp-jira = jira-corp — задачи
- mcp-confluence = wiki-corp — документация, runbook'и
- mcp-bitbucket = bb — репозиторий и PR
- mcp-build = jenkins-corp — сборка
- mcp-deploy = jenkins-corp — деплой

## Джобы CI

- build: джоба `calc-app` (jobFolder `folder/team`), ветка — любая
- deploy: джоба `calc-app-deploy` (jobFolder `folder/team`), стенды в
  порядке DEV → ST → IFT → PSI, стенд передаётся параметром `STAND`

## Известные проблемы (для диагноза ci)

- Стенд ST, агент `st-agent-02`: периодически недоступен — тикет
  DEVOPS-311 (массовая, несколько открытых с тем же симптомом);
  runbook «Deploy / ST agent down» (wiki-corp): перезапуск агента
  силами DevOps, правок репозитория не требует, ретрай на том же
  агенте при стабильном падении бесполезен.
