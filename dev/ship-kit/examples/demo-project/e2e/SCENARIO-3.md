(дефолт task → pr → ci); ваше участие — гейт скилла спеки (утверждение

## ЧТО — сообщения сессии по порядку

**Фаза задачи (спека — сама, по правилам проекта):**

1. `/ship-kit:task PRJ-999 добавь среднее по строкам отчёта.`
2. Скилл спеки ведёт дизайн-диалог (отвечайте коротко, по существу);
   на показанный дизайн — **ок**: утверждение дизайна — гейт скилла
   спеки, без него кода не будет. Далее: план (writing-plans) →
   реализация TDD по чек-листу → коммиты на feature/PRJ-999 →
   авто-переход к pr.
3. Карточка **пуш+PR** → **да** → PR-1 OPEN (мок не мержит сам).

Инъекция MERGED (второе окно):

`node -e "const f='./mcp-state.json',s=JSON.parse(require('fs').readFileSync(f));s.bitbucket.prs[1].state='MERGED';require('fs').writeFileSync(f,JSON.stringify(s,null,1))"`

4. `смержил` → pr сверяет слова с MCP (get_pr → MERGED) → слот
   закрывается → авто-переход к ci.
5. Карточка **запуска build** → **да** → calc-app SUCCESS.
6. Карточка **запуска deploy IFT** → **да** → SUCCESS — план завершён.
