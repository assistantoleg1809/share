# Макросы типовых наборов (опционально)

Макрос разворачивается в перечень для задания — до единого
подтверждения порядка прогона. Файл опционален: без него порядок
называет само задание, не назван — `task` задаёт один вопрос.

## feature — типовая задача

1. спека — скилл спекирования проекта (discovery по списку скиллов
   сессии)
2. имплементация (TDD: красный → правка → зелёный)
3. ревью кода
4. /ship-kit:pr — 🔒 карточка «пуш+PR»
5. /ship-kit:ci — 🔒 build, затем 🔒 deploy по стендам DEV→ST→IFT→PSI
   (каждый запуск — своя карточка)
