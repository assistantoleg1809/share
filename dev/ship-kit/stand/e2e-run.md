# Журнал прогонов тест-стенда ship-kit v3 (dev/ship-kit)

Правила: одна запись на прогон — дата `ГГГГ-ММ-ДД ЧЧ:ММ`, сценарий,
число попыток (зависания flash → retry.sh), вердикт GREEN/RED по
check.sh, дословные строки из финального отчёта (`OK:`, `JOB:` и т.п.)
и из check.sh; провал — короткая причина, фикс — отдельной задачей
(запись в issues не заводится: это стенд, не целевой проект).
Исторические имена не переписывать.
