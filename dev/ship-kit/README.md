# dev/ship-kit — тест-стенд и приёмка ship-kit v3

Всё для проверки комплекта — здесь: моки MCP, песочница одного
прогона, проверка критериев, сценарии, журнал и опросник ревью
(`review.md`). В поставку (`skills/`) не входит; скиллы для прогона
копируются из `skills/` на момент сборки песочницы. Прогоны —
**только glm-5.3-flash**.

## Требования

- `node` ≥ 18, `qwen` CLI в PATH, доступ к glm-5.3-flash;
- из корня репо `~/projects/share`.

## Один успешный прогон (green777) — одной командой

```
bash dev/ship-kit/run_one.sh
```

Скрипт: соберёт песочницу `$TMPDIR/ship-kit/green777` → запустит
агента → проверит критерии (`check.sh`). По шагам то же самое:

```
node dev/ship-kit/make_sandbox.mjs green777
bash "$TMPDIR/ship-kit/green777/run.sh"
bash dev/ship-kit/check.sh "$TMPDIR/ship-kit/green777"
```

**Промпт прогона** (зашит в make_sandbox.mjs, дословно):

```
PRJ-777 возьми задачу: добавь в калькулятор функцию умножения mul(a, b) и вызови её в run(). mcp-tracker=jira, mcp-repo=bitbucket, mcp-build=jenkins, poll=5. Подтверждаю пуш ветки и создание PR. Подтверждаю запуск сборки PRJ-777.
```

Зачем фразы «Подтверждаю …»: в headless нет человека для 🔒-карточек —
дословное «подтверждаю <действие>» в задании = pre-approved (правило
гейтов). `poll=5` — интервал опроса джобы (иначе дефолт 600 сек, и
ожидание RUNNING→SUCCESS растянется).

## Если завис (flash иногда виснет на API-стриме)

Ctrl-C, затем продолжить тот же прогон (план — токен возобновления):

```
bash "$TMPDIR/ship-kit/green777/retry.sh"
```

## Как понять, что успешно

1. `check.sh` печатает все `PASS` и `GREEN` — план-файл создан
   (`.qwen/tmp/ship-kit/PRJ-777/plan.md`), слоты закрыты, PR MERGED,
   джоба опрошена ≥ 2 раз (агент **ждал**, не спрашивал «ждать ли»),
   ветка запушена в bare.
2. В финальном отчёте агента: `OK: true`, статус сборки SUCCESS,
   строки `ДАЛЬШЕ` нет (план закрыт), есть предложение архивации.
3. Итог запиши в `e2e-run.md` (дата, попытки, дословные строки).

## Состав

- `mcp/mock.mjs` — универсальный мок MCP (jenkins·jira·confluence·
  bitbucket·sonar; состояние в файле, первый опрос джобы — RUNNING);
- `make_sandbox.mjs` — песочница: git-репо + bare, фикстуры, сид,
  копия `skills/ship-kit-*`, `.qwen/settings.json` с моками, раннеры;
- `run_one.sh`, `check.sh` — прогон одной командой и критерии;
- `SCENARIOS.md` — сценарий green777 и как расширять RED-сидами;
- `e2e-run.md` — журнал прогонов;
- `review.md` — опросник ревью с эталонами (приёмка = стенд + опросник).
