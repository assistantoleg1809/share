# dev/ — воркспейс разработки расширений

Конвенция: каждому расширению `extensions/<имя>/` (эталон — устанавливается
целиком, только поставляемое) соответствует свой каталог разработки
`dev/<имя>/`. Чьё — видно по имени; расширений может быть много.

| Путь | Что |
|---|---|
| `sync-reference.sh [имя]` | обновление установленной копии эталона (uninstall → install --consent; дефолт — ship-kit) |
| `ship-kit/` | разработка ship-kit — карта внутри: [ship-kit/README.md](ship-kit/README.md) |

Новое расширение: `extensions/<имя>/` (эталон) + `dev/<имя>/` (разработка);
модельные прогоны — только на `glm-5.3-flash`.
