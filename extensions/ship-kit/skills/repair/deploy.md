# repair · deploy — исправление деплоя

Профильная команда — команда деплоя/DevOps; твои причины только те, что
правятся конфигом или кодом репозитория.

## Область правки

- `config`: конфигурация деплоя/окружения в репозитории (пути, параметры,
  версии артефактов).
- `code`: скрипты деплоя/миграции в репозитории.

## Границы

- Инфраструктурные причины (диск, агент, сеть, место) — не твои:
  not-fixable с тикетом DevOps из диагноза.
- Не править окружения за пределами репозитория.

## Проверка

- Для конфигурационной правки — валидация конфига/синтаксиса до и после
  (вместо «красного» теста).
- Для скрипта — запуск упавшего шага локально, где воспроизводимо;
  иначе честно указать замену проверки.
