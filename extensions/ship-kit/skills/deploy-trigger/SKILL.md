# deploy-trigger — кнопка «Запустить деплой»

Одна задача — один вызов инструмента запуска деплоя. Повторы, ожидание
статуса, чтение логов — не здесь. Запуск сборки — соседний скилл
`build-trigger`.

## Шаг 0 — проверка MCP из аргументов (обязательна)

Скилл не выбирает сервер сам: MCP для запуска (alias `mcp-deploy` →
фактический сервер) и название джобы передаются аргументами вызова.
Не передано — запроси у пользователя, какой MCP использовать (id сервера
из settings.json → mcpServers), и остановись до ответа; не подбирай молча.

Убедись, что инструмент запуска деплоя доступен на переданном сервере
(объявлен напрямую или найден через tool_search). Инструмента нет — верни
блок ошибки и остановись:

```
❌ Инструмент запуска деплоя недоступен
Симптом: <чего не хватает, дословно>
Рекомендации:
1. Выполнить /mcp — жив ли переданный сервер и как называется инструмент запуска деплоя.
2. Сверить alias mcp-deploy с фактическим id сервера в файле проектов
   (ship-kit.projects.md) и settings.json → mcpServers — их читает
   вызывающий, не ты.
3. Перезапустить сессию Qwen Code — клиент не перезапускает MCP сам.
```

## Протокол

1. Один вызов запуска с переданными параметрами. Повторы запрещены: упал
   вызов — так и отчитайся, ретраи делает вызывающий, не ты.
2. Аргументы приходят полностью от вызывающего: если параметры запуска не
   заданы, вызывающий сам берёт их из предыдущей успешной джобы и передаёт
   тебе — наследование не твоя забота. Ничего не искать: не перечислять
   джобы, не сканировать сервер, не угадывать пути. Аргумента нет — верни
   ошибку с перечнем недостающего, без попыток доугадаться.
3. Из ответа возьми номер запуска и URL.
4. Статус деплоя не ждать — за это соседний шаг (скилл `deploy-status`).

## Ограничения

- Кроме инструмента запуска деплоя ничего не вызываешь.
- Только MCP, переданный аргументами вызова. Файл проектов не читается:
  alias→сервер знает вызывающий, не ты.
- Параметры не придумывать: не передали — дефолты джобы.

## Формат отчёта

ok: true/false; deployNumber; url; error (при ok=false — дословно что вернул
инструмент).
