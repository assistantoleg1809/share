# e2e-сценарии ship-kit v2 (стадийная модель)

Протокол уровня 3: дословные прогоны скиллов на дешёвой модели
(`glm-5.3-flash`) в сессиях-песочницах. Моки MCP — файловое состояние
(`dev/ship-kit/e2e/mcp/`, подключаются settings.json песочницы по alias из
реестра), изоляция git — bare+клон (`dev/ship-kit/e2e/bare.git`,
`e2e-run/`, gitignore). Реестр песочницы — копия фикстуры
`../tests/fixtures/calc.yaml` (или billing/спец-реестр сценария).

Правила прогонов: сброс состояния моков перед сценарием; детерминизм
(первый запуск FAILURE, далее SUCCESS; первый статус RUNNING, далее
терминальный); журнал сессии — `dev/ship-kit/e2e/e2e-runs.md` (дословные
промпты и исходы; исторические имена не переписывать).
