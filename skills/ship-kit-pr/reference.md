# ship-kit — общие инварианты комплекта

Контекст для всех фаз: `ship-kit-task` (разработка), `ship-kit-pr`
(доставка), `ship-kit-ci` (сборка/деплой). Правила фазы — в её
SKILL.md; здесь — общее. Комплект ставится копией каталогов в
`~/.qwen/skills/` или `.qwen/skills/` проекта — фазы независимы
(частичная установка), соседи ищутся в списке скиллов сессии.

## Единица работы — фаза

Один вызов проходит фазу целиком: один Шаг-0, основная работа, один
контракт отчёта. Цепочка слотов авторизована планом: закрытый слот
продолжается следующим незакрытым — модель вызывает его сама
(инструментом вызова скиллов), человек имена скиллов не печатает;
паузы — только 🔒-гейты и вопросы правил; конец плана — стоп.
Одиночный вызов человеком вне плана — выполняется без цепочки.
Переход между вызовами вне плана — человек одной короткой фразой
(строка `ДАЛЬШЕ:` в отчёте).

## Каскад аргументов

**Задание > конвенция проекта > один вопрос человеку** (закрытыми
опциями, если инструмент вопроса есть в сессии). Конвенция — обычный
контекст сессии: файлы проекта; при нескольких источниках — файл
проекта в репо (cwd) мастер, центральный каталог — автособираемый
индекс. Конвенции может не быть: обязательное не названо — спроси.
MCP-роли: **tracker · docs · repo · build · deploy · quality ·
vuln · chat**; несколько MCP роли — через запятую: все рабочие,
чтение по всем, запись — куда названо заданием, иначе один вопрос.
Конкретный alias не назван нигде — в проекте этого MCP нет: работай
без него и честно отметь. Ни одного и конвенции нет — вопрос и стоп.

## Гейты 🔒 — три правила

Необратимое (пуш, создание PR, запуск джобы, ответы на комментарии) —
карточка-превью → явное «да» → действие; отказ = стоп без перебора
альтернатив; дословное «подтверждаю …» в задании = pre-approved.
Есть инструмент вопроса с закрытыми опциями — гейт спрашивается им:
согласие = утвердительная опция, текст вне опций — не подтверждение
(ответь на содержание, переспроси один раз, затем стоп). Инструмента
нет — текстовый канал: подтверждение = дословная фраза целиком из
списка «да» · «ок» · «подтверждаю» · «подтверждаю <действие
карточки>»; отказ — «нет» · «стоп»; прочее — переспрос один раз,
затем стоп.

## Транспортные сбои

Таймаут/обрыв MCP или git, сетевая ошибка — повторяй тот же вызов
автоматически, до 2 повторов, без вопросов и без повторного гейта
(действие уже авторизовано, состояние не менялось); исчерпаны —
честная ошибка и стоп.

## Границы

- Пуш — только в рабочие ветки `<X>/<КЛЮЧ>` (или тех-ветку от
  базовой); целевые ветки (main/master/develop/release, база PR)
  запрещены — сверяй до любых действий.
- Статусы задач трекера не меняет никто; комментарии — только по
  явной просьбе.
- Ничего не искать: джобы, пути, репозитории, PR — из задания,
  конвенции или вопроса, не сканированием серверов.
- Правки репозитория — только через PR.

## Состояние прогона

План-файл — общее состояние. **Директория прогона — каскадом:
задание назвало директорию → конвенция проекта → дефолт — временная
`.qwen/tmp/ship-kit/<КЛЮЧ>/` проекта**; определённая директория несёт
уровень проекта — `<директория>/<ПРОЕКТ>/<КЛЮЧ>/`; `issues.md` —
рядом с планом. Каждый запуск скилла материализует план: найти по
ключу или создать (первый вызов любой фазы). Журнал: каждая запись с
даты и времени `ГГГГ-ММ-ДД ЧЧ:ММ` (локальное время), затем событие.
`<ПРОЕКТ>` — из конвенции (файл проектов), иначе имя каталога
репозитория; worktree прогона — `<ПРОЕКТ>-<КЛЮЧ>`. Архив завершённого
прогона — `<корень прогонов>/archive/<КЛЮЧ>/` (корень — тот же
каскад; дефолт `.qwen/tmp/ship-kit/archive/` — временный, честная
пометка в отчёте). План по умолчанию = установленные фазы комплекта
(`task → pr 🔒 → ci 🔒`); фаза не установлена (имени нет в списке
скиллов сессии) — пометка «фаза не установлена» в плане и отчёте,
слот исключается, без вопроса. Возобновление — «продолжи <КЛЮЧ>»
(канонический вход `ship-kit-task`) или узкой фразой своей фазы;
скилл читает план, сверяется с фактическим состоянием и продолжает.

## Верификация отчётов

`OK: true` — только с дословными свежими строками прогона/статусов
этого вызова; без свежих доказательств успех не заявляй.
