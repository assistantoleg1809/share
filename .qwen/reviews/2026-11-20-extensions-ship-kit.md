## Findings — 4 Suggestion (0 Critical)

### f3 — task/SKILL.md:48 — разрыв предписания списком ролей

**Что не так:** правило про отсутствующий alias разорвано: «Конкретный alias
не назван нигде — в» / [Роли алиасов] / «проекте этого MCP нет: работай без
него…».
**Сценарий отказа:** flash-модель читает Шаг-0 линейно; правило тихой
деградации теряется — в ci/SKILL.md то же правило цельным абзацем.
**Свидетельство:** grep -A4 «не назван нигде» → строки 48–52.
**Фикс:** склеить фразу, список ролей перенести после неё (как в ci).
**Fix witness:** grep «не назван нигде — в проекте этого MCP нет» одной строкой.

### f2 — task/SKILL.md:114 — тип-набор против чек-листа задания

**Что не так:** п.4 (тип-набор) и п.2 (чек-лист внешних скиллов с одним
подтверждением) не связаны: приоритет перечня задания над набором типа не заявлен.
**Сценарий отказа:** «PRJ-42 (business), примени скилл X» — модель выполняет
оба набора / один наугад / спрашивает дважды.
**Свидетельство:** п.2 «одно подтверждение», п.4 «Набор типа: …» — перекрёстной
ссылки нет ни в одной из трёх точек правила.
**Фикс:** строка в п.4 «задание перечислило скиллы — перечень сильнее набора
типа» + дубли в QWEN.md и docs п.4.
**Fix witness:** новый сценарий дельты «перечень задания против набора типа».
**Fix constraint:** не вводить второй вопрос (п.2 — ровно одно подтверждение).

### f1 — specs/base-skills/spec.md:81,463 — легаси-пути в мейн-спеке

**Что не так:** «`skill-runs/<КЛЮЧ>/plan.md` создаётся **всегда**» (81) и
«провал … в `skill-runs/<КЛЮЧ>/issues.md`» (463) противоречат требованию
«Состояние прогона» (новые прогоны только `runs/<ПРОЕКТ>/<КЛЮЧ>/`) и всему
комплекту.
**Сценарий отказа:** будущий change пишется по спеке как контракту и
закрепляет легаси-путь для новых артефактов.
**Свидетельство:** grep skill-runs по спеке → 81, 463 (активные) против 367,
394–396 (легаси-чтение); в extensions/ship-kit — только легаси-упоминания.
**Фикс:** точечный синк двух строк.
**Fix witness:** после правки grep возвращает только легаси-строки.
**Fix constraint:** легаси-строки 367, 394–396 — контракт чтения, не трогать.

### f4 — docs/ship-kit.md:103 — имя спек-инструмента в поставке

**Что не так:** чек-лист адаптации: «permissions.allow … для рабочих команд

исполнителя слота» ослаблен.

совпадение, docs/ship-kit.md:103.
**Фикс:** «(git/<CLI спек-инструмента проекта>/node)».
**Fix witness:** grep → 0 совпадений.
